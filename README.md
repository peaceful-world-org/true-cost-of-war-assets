## What this repository does

This repository is the public delivery layer for browser assets used by Peaceful World's True Cost of War pages.

The application source, research, data work and development branches live in a private repository. This repository intentionally contains only browser-deliverable runtime assets.

Tilda pages load a stable language-specific bootstrap from this repository. Each bootstrap points to the currently approved immutable production loader. Updating production therefore no longer requires replacing the T123 snippet on every Tilda page.
